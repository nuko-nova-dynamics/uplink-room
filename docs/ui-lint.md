# UI lint

`pnpm lint` runs the existing oxlint check and the UI check. CI already uses this command on Linux and Windows. The UI check covers every CSS file and every non-test TSX file under `apps/desktop/src/renderer`. Gym fixture TSX is excluded. See [the tool research](../research/ui-lint-tools.md) for versions and measurements.

| Rule                                      | What it forbids and prevents                                                                                                                                                 | Fix                                                                                                                                                                                                                     |
| ----------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `css/tokens`                              | Raw nonzero pixels, colors, durations, radius values and z-index outside custom-property definitions. Prevents drift between components and themes.                          | Use an existing token or define a named semantic token. Zero, `transparent` and `currentColor` are allowed. Existing pixel media queries remain in the baseline because CSS does not allow `var()` in media conditions. |
| `css/scale`                               | Spacing, font sizes and icon dimensions outside their respective token scales. Prevents near-matching gaps and sizes.                                                        | Use `--space-*`, `--font-*` or `--icon-*`. Existing `--fs`, `--row-pad`, `--edge` and `--gutter` are also accepted in their family. A new one-off token does not enter the scale automatically.                         |
| `css/focus-visible`                       | `outline: none` or zero without a visible outline, shadow or border for the same selector at `:focus-visible`, in the same media context. Prevents invisible keyboard focus. | Remove the reset, or add a visible focus replacement. A generic global focus rule does not excuse a more specific reset. When a container already shows focus (`:focus-within`) or the element is a text surface whose caret shows it, add the exact file, selector and property with its reason in `scripts/ui-lint/exceptions.json`.                                                                                                |
| `css/transition-all`                      | `transition: all`, `transition-property: all`, and duration-only shorthand. Prevents unrelated property changes from animating.                                              | Name each property.                                                                                                                                                                                                     |
| `css/transition-layout`                   | Transitions on dimensions, offsets, spacing, grid, flex, font size and other layout properties. Prevents layout shifts while animating.                                      | Animate transform, opacity or color.                                                                                                                                                                                    |
| `css/no-important`                        | `!important` outside an exact exception. Prevents overrides that become hard to change.                                                                                      | Fix the cascade. For a third-party override, add the exact file, selector and property with its reason in `scripts/ui-lint/exceptions.json`. Existing exceptions not yet reviewed remain counted in the baseline.       |
| `css/no-side-stripe`                      | A colored left, right, inline-start or inline-end edge wider than 1 px. Checks shorthands and split width/color declarations. Prevents the accent side-tab treatment.        | Use a neutral divider or a full outline. Neutral quotation rules remain valid.                                                                                                                                          |
| `ui/no-inline-svg`                        | Inline SVG outside `Icon.tsx` and named art files. Prevents competing icon families.                                                                                         | Add the glyph to `Icon`, or document a real artwork exception in `artFiles` in `scripts/ui-lint/tsx.mjs`. The wordmark and character files have explicit reasons there.                                                 |
| `ui/no-emoji-icon`                        | Emoji used as a control or decorative icon. Prevents platform-dependent icon shapes and colors.                                                                              | Use `Icon`. Emoji in prose and the reaction picker are content and remain allowed.                                                                                                                                      |
| `ui/no-inline-px`                         | Pixel strings and templates in inline styles, plus numeric React length properties. Prevents styles from bypassing CSS tokens.                                               | Use a CSS class with tokens. Unitless opacity, flex factors and zero remain allowed.                                                                                                                                    |
| `ui/icon-scale`                           | Literal `Icon` sizes outside 12, 14, 16, 18, 20 and 24. Prevents mismatched icon sizing.                                                                                     | Choose a size from the shared icon scale.                                                                                                                                                                               |
| `react/button-has-type`                   | Buttons without an explicit valid type. Prevents accidental form submission.                                                                                                 | Set `type="button"`, `submit` or `reset`.                                                                                                                                                                               |
| `jsx-a11y/click-events-have-key-events`   | Click handlers on noninteractive elements without keyboard handlers. Prevents mouse-only controls.                                                                           | Prefer a native button. Otherwise support Enter and Space with a suitable role and focusability. Where a view's own key handler is the keyboard path (the Inbox's rows), disable the rule on that line with a comment saying so.                                                                                                                        |
| `jsx-a11y/no-static-element-interactions` | Interactive handlers on static elements without a role. Prevents controls hidden from assistive technology.                                                                  | Use the right element or role. Event-delegation and dismiss-scrim containers can use `presentation` when their child controls and Escape handling provide the interaction.                                              |
| `jsx-a11y/control-has-associated-label`   | Controls without a text label or accessible name. Prevents unnamed controls.                                                                                                 | Add visible text, an associated label or an accurate `aria-label`.                                                                                                                                                      |
| `ui/icon-geometry`                        | A viewBox other than `0 0 16 16`, strokes other than 1.5, or geometry extending beyond the viewBox including half the stroke. Prevents clipped or inconsistent icons.        | Adjust the authored geometry. Filled silhouettes have no stroke inset. Geometry must be static and inspectable. The final viewBox follows spread props so callers cannot override it.                                   |

The checker uses parsed CSS and TSX, so comments and quoted examples are not treated as declarations or elements. CSS syntax errors and icon geometry errors cannot enter the baseline. The checks are source guards; they do not prove rendered contrast, focus order or pixel alignment. The UI gym covers those separately.

## Baseline

`scripts/ui-lint/baseline.json` stores counts by repository-relative file and rule, never by line. Both increases and stale decreases fail normal lint. Moving a violation to a different file or rule counts as an increase there.

After fixing existing violations, run:

```sh
pnpm lint:baseline
pnpm lint
```

The update command refuses any increase before writing the file. It only preserves or lowers existing counts, and removes entries that reach zero. Review baseline changes with the fix. Do not regenerate it from scratch or raise a count by hand. New files start with zero allowance.

The scale was derived from DESIGN.md's 6 px control gap, 8 px row spacing, 14 px icons, 13 px labels and 15 px messages, plus the existing CSS's common spacing, density and type values. Adding the tokens does not change existing rendered values. DESIGN.md itself was not edited.
