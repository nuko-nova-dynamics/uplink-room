# Uplink Room never runs an agent itself

Uplink Room is the team layer: people, channels, calls, projects, tasks, runs and the inbox. Every agent comes in through a tool that already runs it: T3 Code for harnesses such as Claude Code and Codex, Cua for Spaces, and A2A for agents such as Hermes and OpenClaw. We chose this over building our own harness so that people keep their own subscriptions and we don't compete with the tools we connect to. The cost is that we depend on young projects and can only show what their APIs expose (see open experiments 1, 2 and 4 in `research/notes.md`).
