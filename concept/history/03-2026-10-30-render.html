Malecón

A shared space where the team and all of its agents work together. Malecón doesn't build agents. It connects the ones you already use (Claude Code, Codex, Grok, Hermes, OpenClaw) through the tools that already run them (T3 Code, Cua Spaces), and adds what a team needs around them: channels, calls, projects, and one view of everyone's work.

Named after Guayaquil's riverfront promenade. A working name. Internal first; a product later if it earns it.

To test first

Questions the docs don't answer. Each one is a small experiment.

  1. Live thread viewCan Malecón embed T3 Code's web client for a thread, or do we reuse its client code (MIT)? Try both on one machine.
  2. Enough for the boardDoes T3 Code's MCP server report when a thread is waiting for input, or does Malecón need its client protocol?
  3. Shared subscriptionsT3 Code says it stays within Claude Code's, Codex's, and Antigravity's terms. Check whether teammates prompting a thread on one person's subscription is allowed, or give shared machines their own accounts.
  4. Spaces inside MalecónCan a Space be shown in our app, or only in Cua's? Can it run on Daytona VMs, or only on machines we control?

Open-source developer preview. Chat with teammates and agents, then plan, code, and open PRs in one place.

Where Malecón is different

Each of these pushes one company's agent or one company's chat. Malecón sits a layer above: it doesn't compete with T3 Code, Cua, or any agent, it brings them together for a team. That neutrality is the opening.

Risks

  • It depends on young projects. T3 Code is at v0.1.x and guest links and linked machines are beta. Both T3 Code (MIT) and Cua Spaces (source-available) can be forked if needed.
  • Selling it later: Cua Spaces' license forbids competing products, so a paid Malecón would need Cua's hosted plan or a deal with them.
  • Agents with computers and saved logins are a security target.
  • Slack already ships code channels, and Buzz is free.

Build order

Each step is usable on its own before the next one starts.

  1. ChatElectron app, Clerk sign-in, channels, threads, DMs, and file uploads on Convex.
  2. CallsVoice channels, video, and screen share with sound on LiveKit.
  3. Connect T3 CodeLink each teammate's machine and one shared box. Threads show up in projects; anyone can follow, the owner drives.
  4. Connect Cua SpacesThe office PC and one Linux VM as shared desktops, linked to runs.
  5. ProjectsThe board of runs, the waiting-on-you inbox, and attempts across agents.
  6. Open the doorsA2A for Hermes and OpenClaw, and Malecón's own MCP server.
  7. Files, apps, and browsersPDFs, docs, canvases, HTML apps in messages, and shared browsers.
