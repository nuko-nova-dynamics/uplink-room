Characters, mascot and the brand around them

Your note on round 2: the brand should feel like Grok Bot and Muse, with real icons, animation and mascots. These are three character systems, each with a house mascot (the larger one, with an antenna ending in Uplink Room's amber dot) and six agent characters told apart by body shape, color and one accessory: headphones for a notetaker, a wrench for a deploy bot, and so on. They are generated explorations, not final art; the chosen style gets redrawn as clean vectors with state animations next. Press Send answers to Claude when you're done.

The same cast in three styles. Grok Bot tested many styles and kept simple shapes with expressive eyes because detailed styles (watercolor, clay) lost their character at sidebar size.

The glossary separates them: an agent is a team member a person added (Hermes, a notetaker); a harness is the tool running a thread (Claude Code, Codex).
